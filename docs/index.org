** Where to start
:PROPERTIES:
:CUSTOM_ID: where-to-start
:END:

If you have never built a stylesheet, read [[file:getting-started.org][Getting started]].  If you know
Tailwind and want to know what is different, read [[file:comparison.org][Compared with Tailwind]] and
then the [[file:reference.org][utility reference]].  If you are shipping to production, read
[[file:tree-shaking.org][Tree shaking]] - it is the step that turns the multi-MiB complete build into a
few KiB.

If you are changing Olive CSS itself, read [[file:development.org][Development and releases]]
before touching a task or the release process.
