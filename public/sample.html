Utility-class CSS, the libre way

Olive CSS is a utility-class framework written in Guile Scheme. Ship the tree-shaken build and only the classes you actually use reach the browser.

Hackable

Extend or override anything with plain Scheme code.

Minimal dependencies and fast, reproducible builds.
